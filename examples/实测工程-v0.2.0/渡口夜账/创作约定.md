# 《渡口夜账》创作约定

本轮授权创作现实悬疑长篇的开篇连续三章，并提供相应的设定、细纲与可供后续提交使用的初始输入。不扩写全书，不生成第四章；之后的审查、修订或文件恢复请求不视为第四章写作授权。

故事发生在虚构县城老渡口停航交接的最后一夜。人物要面对借物未销账、实物被归错类别、凭据不完整和交接期限；调查由人物选择、现场核对与真实可见的纸面记录推动。没有超自然力量，没有能直接得知真相的全知主角，不援引真实城市、现实法规或未经核实的设备管理规定。

叙述采用第三人称，以江棠的现场经历为主要视野。杜承安、关岚和唐恕各自掌握的事情须经对话、凭据或动作进入江棠的知识范围。设定文件中的作者安排不等于人物已经知道。

每章正文须为 2200—2800 个可见字符，使用 `visible_nonspace_v1` 口径：不计首行 Markdown H1 标题、空白和 Unicode 控制/格式字符；标点、数字及字母计入。三章不另设导语或前情提要，不以附录、设定或审查文字补足正文长度。此统计不冒称任何平台的官方字数。

开篇必须建立并在第三章兑现一个具体承诺：明早接收车出发前，查清十九号泵的去向。查清实物不等于抹去杜承安私下转借的事实。三章结束时，可以确认北库十九号和新编三十七号为同一实物；不能确认南岸确有第二台同号泵，更不能据清册重复行认定谁伪造账目。

长线只留下一个主要问题：相同出厂号为何在两岸清单中分别计数，另一行到底对应什么实物或原始记录。江棠本轮只签自己的已核范围，整理费是否能够按原先承诺到账尚未解决。

`drafts/01.md`、`02.md`、`03.md` 保留原创初稿。作者自查与独立审稿分别记录，见审稿记录.md。主任务另存 `03-r1.md` 修复具体交接表达、`03-r2.md` 完成下述决定调整；不得用修订稿覆盖初稿。
