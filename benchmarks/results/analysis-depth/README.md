# 作品深读：本轮实现与探索性对照

日期：2026-09-10。对比已发布 v0.5.0 与尚未发布的 v0.5.1 技能快照。六题各生成一份旧版和新版报告，共十二份；每份使用独立的新代理上下文。两名未参与生成的代理完成匿名评阅。

**两名评阅者在第 02 题都轻微偏好新版，其余题目相近、各有优势或存在评阅分歧。** 这轮发现了局部解释收益，尚未证明分析质量稳定、普遍提高，更不能据此授予“大师级”评价。

## 实际执行条件

- 输入为 [六组原创合成材料](../../analysis-depth/README.md)，四组开发题、两组留出题。技能和协议在生成前冻结；留出原文此前未提供给主代理或技能编写代理，材料作者必然见过自己编写的文本。
- 每题每版一次，共十二个无前文的生成上下文；全部继承同一宿主设置，没有显式覆盖模型或推理档。宿主未暴露的精确型号、温度和实际用量记为空值，不能声称已控制未提供的参数。
- 两组任务和原文一致，均要求正文 500—800 字、只依据给定文本、允许有依据的不同解释。任务只交付单篇分析，不建立书库；本轮不代表完整分析 CLI 通路的模型实测。
- 原始输出全部保留。正文按去标题、去空白字符计为 705—778 字，十二份均符合范围；此口径含标点，汉字数另行记录。六份新版读取记录均包含深读规范，教学样例未被这六次运行读取。
- 匿名编号的随机种子为 20260910，在生成后、评阅前确定；主代理当时只查看完成和长度记录。映射未提供给评阅者。两份判断分别完成后解盲，原始判断保持原样。
- 这是匿名代理评阅，没有人类编辑参与，每题没有重复采样。固定六题全部报告，不按结果选优；本轮没有根据这些输出继续改动技能。两道留出题已经用于本轮，后续调试不能继续把它们当作未见样本。

固定输入、技能文件摘要、生成范围与读取记录见 [manifest.json](manifest.json)；匿名标签见 [blind-mapping.json](blind-mapping.json)。评阅采用 [预先冻结的协议](../../analysis-depth/protocol.md)。

## 逐题结果

“相近”指没有稳定的整体优劣；“各有优势”保留不同维度的取舍，不能换算成胜负或综合分。

| 02 叙述者的知识与可信度 | 轻微偏好新版 | 轻微偏好新版 | [旧版](reports/baseline/02/report.md) · [新版](reports/candidate/02/report.md) |
| 03 间隔章节的信息重估 | 相近 | 各有优势 | [旧版](reports/baseline/03/report.md) · [新版](reports/candidate/03/report.md) |
| 04 克制表达与留白 | 各有优势 | 相近 | [旧版](reports/baseline/04/report.md) · [新版](reports/candidate/04/report.md) |
| 05 不同叙事目标的节奏（留出） | 各有优势 | 轻微偏好新版 | [旧版](reports/baseline/05/report.md) · [新版](reports/candidate/05/report.md) |
| 06 记录形式与主题（留出） | 轻微偏好新版 | 相近 | [旧版](reports/baseline/06/report.md) · [新版](reports/candidate/06/report.md) |

两位对第 02 题的共同判断是：新版通过设想提前交代竹帘，解释信息顺序如何改变读者信任；同时说明“真诚误记”与“求关注”可以并存。这是具体样本中的机制解释收益，不能外推为所有叙述者分析都会改善。

第 03—06 题的分歧也有价值：旧版有时更直接限定动作与心理的区别，新版有时更清楚限定人物说法、物件作用或前后文关系。两边都已有可用的分析，增加规则并未让每题都产生清晰优势。完整五维记录、理由和限制见 [评阅者 1](reviewer-1.json)、[评阅者 2](reviewer-2.json)，解盲后的逐题对应见 [comparison.json](comparison.json)。

## 待复核措辞

两位评阅者均未登记确定的硬事实错误，但这不表示所有推断都已证实。三处措辞保留为 `pending`，不折算成错误率或扣分：

| 报告 | 待复核处 | 证据边界 |
| --- | --- | --- |
| 旧版 05 | “借饭盒” | 原文写取下饭盒、试盖和找橡皮筋，未明确写出借出；可能是在概括行动意图。 |
| 旧版 06 | “迟迟没有完成” | “待问”说明记录当刻未决；“迟迟”可能是在描述阅读悬置，也可能把时间说得过强。 |
| 新版 02 | “翻转双手” | 原文“自己的手”未明确数量；汉语可以不标单复数，保留字面精度争议。 |

此外，评阅者对异响警戒意图、接应人说法是否可靠等解释强度提出补证意见，详见各份 JSON 的 `limit` 和 `needs_support`。保留原始分析与分歧，供后续真实作品评阅检验。

## 工程检查与适用范围

[本地回归](unit-tests.json) 共 390 项：383 通过、7 项平台专用跳过，零失败或错误。[九项开发检查](technical.json) 通过，覆盖 CLI 冒烟、中文稿重放、多线重放、隔离安装、指令哈希、当次本地链接、33 文件开发包、七技能官方校验和技能文件稳定性。这是本轮开发检查，不是完整新版本发布验收；新远端 CI、容量/迁移复验和发布尚未执行。

[静态指令计数](tokens.md) 记录深读所需指令由 2,334 增至 4,063 tokens，含按需教学样例时为 5,600；没有统计实际账户消耗，也不据此推导文学质量。

这些短文本的叙事安排较集中，无法替代复杂长篇、真实作者文本或人类编辑评阅。下一轮应增加未参与调试的真实作品样本，并保留重复生成与人类分歧；本轮结果只支持上述局部判断。
