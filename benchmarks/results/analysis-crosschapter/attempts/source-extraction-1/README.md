# 完整分章作品的单次验收

本轮固定当前 v0.5.1、给定原文和任务，只生成一次，不与旧版比较。生成者使用全新上下文，只接触技能、正文、目录和自然任务，不看本协议、旧评阅或外部评论。执行参数继承宿主，未暴露参数记为不可控。技能字节、输入和旧结果哈希见结果目录 manifest.json。

独立模型评阅者接收原文、目录、任务和原始报告，未参与生成。程序证据与语义判断分别检查，不设总分：

1. 目录九章与文本和导入块能对应；完整覆盖只指此次页面正文，不能代替扫描校勘或其他版本核对。
2. 对报告最重要的三项跨章结论（含人物变化）检查起点、转折、结果和必要邻文是否真正回读，论证能否连接证据；不按次数评优。
3. 判断人物改变或不变时，核对诉求、处境、选择与代价，避免把情境变化直接等同觉醒或成长。
4. 核对主语、时间、发言身份，区分事件、人物自述、叙述者评价与分析推断；反讽不等于无条件取反，叙述者不直接等同作者私人意图。
5. 反例与竞争读法须对结论产生实际影响：保留、缩小、放弃或暂不取舍有理由，不以谨慎词替代证据。
6. 机制解释与迁移建议给出具体操作、成立条件和失败风险，不搬用独特剧情。

各项以“成立／需修订／证据不足”给出报告原句、原文位置和理由。错引、动作归属与虚构事实另记；合理不同读法不计硬错误。程序单独核对输入哈希、章块范围、精确引文、覆盖、保存和重开状态。

保留原始输出。基础设施错误保留失败后恢复；语义问题不重新生成挑优，必要时另存修订稿并只复核改动及依赖结论。停止条件是完整导入覆盖和报告保存完成、核心跨章判断已核对、必须修改的问题已解决或明确限定无法验证。一般审美改进建议不触发无限重写。

仅一部作品、一个版本、一次生成和一名模型评阅者，不能估计输出波动、证明质量提升或人类认可。名作可能出现在训练资料，不是未见留出；完整分章中篇不代表超长连载。此轮若发现技能问题，仅登记下一步候选，不改变冻结技能并沿用旧结果为新字节背书。
