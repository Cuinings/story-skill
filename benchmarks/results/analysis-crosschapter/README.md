# 《阿Q正傳》完整九章试用

本轮固定开发版 v0.5.1，使用一名全新上下文的生成者完成一份全篇分析，再由未参与生成的模型独立评阅。没有旧版对照、重复采样或人类编辑；技能全程未改。本机已安装的七项技能与本轮冻结的 33 个文件一致，不能把这次通过解释成“大师级”认证或稳定质量提升。

建议阅读 [澄清后的分析稿](clarified/report.md)。它只落实原评阅的两项可选建议，保留 [原始定稿](original-report.md)、[带来源头的工具导出](tool-report.md) 和 [独立评阅](review.json)；没有覆盖书库中的定稿。

三项核心判断分别是：精神胜利能暂时修复受辱感，却不能取消外部代价；关系认可随资源与威胁改变，革命尝试延续等级欲望；信息与观看角色的安排使人物感受被他人的定名和裁断取代。评阅逐项给出原句、前后证据及解释边界，不设总分。

[程序回执](technical.json) 与文学判断分别保留。[评阅位置核对](review-check.json) 验证了评阅中的 91 处报告或原文引文范围，并把三项核心判断映射到生成期间的实际回读。评阅引用的 19 处核心证据中，18 处包含在回读输出中；第五章末尾决定进城一处由完整初读覆盖。重要判断的前后证据均有回读，但不声称每处评阅证据都重新读过。17 条报告引文中有 16 条包含在回读输出，另一条“革過”来自已读块；[逐引文映射](report-reread-links.json) 还保留短语多处出现的歧义。

## 回读产生的修正

生成者在定稿前修订了块 5 和块 14：收回“永久失去赵家工作”的过强表述，将“赵太爷不会错”的章节明确定位到第三章。原输入和替换后的输入、事件记录均保留。这说明本次输出发生过根据后文作局部修正，不能归因于某一句技能规则。

独立评阅的两项建议为可选澄清，不是必须修正的实质误读。第一项说清革命身份想象早于“老Q”称呼，且自封与盘辫仍带来礼遇，只是没有取得参与资格；第二项将失败风险限定于让自欺累积成悲剧及塑造悲剧回声的目标。编辑据此另存新稿，并作 4 处原文回读；这些后续读取不计入原始生成的 21 次。[修改与进度](clarified/progress.json)、[后续回读](clarified/rereads.json)、[限定复核](clarified/review-followup.json) 单独保存。

## 失败与核验边界

- 来源提取最初混入两处网页链接域名尾标。发现时只有导入、没有已保存分析或报告；保留 [初次尝试](attempts/README.md) 后修正 37 个码点，重新冻结输入并以新上下文开始一次完整生成。[来源修正](source-correction.json)、[独立材料核验](source-audit.json)、[提取说明补充](source-documentation-followup.json) 均保留。
- 生成期间的回读定位辅助脚本因“于是／於是”字符不一致失败一次，修正锚点后恢复；失败脚本和标准错误保留在 [过程记录](run/process.json) 指向的文件中。首轮技能读取日志由已成功读取的相同文件字节补存，其余调用通过包装器捕获；这些记录不是独立的系统访问审计。
- 重开检查最初错误地要求整个数据库字节不变，随后又把全部表字段不变作为条件，两次均保留为 [初次回执](reopen-check-initial.json) 和 [字段检查回执](reopen-check-logical-initial.json)。实际运行会更新 `integrity_audits.created` 核验时间。确认这一行为后再检查：仅排除该时间字段，其余数据库逻辑内容、核验版本和文件数、报告与原提交文件均未变。[最终重开回执](reopen-check.json) 不是故障注入，也不声称数据库文件字节不变。

原文来自 [本次来源材料](../../analysis-crosschapter/SOURCE.md)，保留作者、网页版本、提取方式及授权说明。完整范围是本次可见页面的九章正文，没有扫描校勘；作品可能见于模型训练材料，不是未见留出，也不能代表超长连载。原作不随项目 MIT 许可重新授权。

## 保存和复核

[冻结记录](manifest.json) 绑定技能、任务、协议、来源和 283 份既有结果；[生成结束快照](generation-snapshot.json) 记录本轮原始文件。旧结果、原稿及原评阅均保留，只有本轮新增的材料、报告与当前说明文档发生变化。

本机分析工程位于 `run/`，可以直接找回定稿；SQLite 按仓库通用规则只保留在本机，提交材料包括原始输入、逐块 JSON、命令与完整输出、报告和回执。只读复核脚本为 [audit_run.py.txt](audit_run.py.txt)，重开脚本为 [reopen_check.py.txt](reopen_check.py.txt)，均使用 Python 3；重开脚本会刷新核验时间。历史日志保留当时绝对路径，异机重放应定位同版技能并使用新的独立工程，不能直接套用这些路径。

本轮没有改技能、运行时或打包文件，也没有重跑此前 390 项回归或静态 token 计数；当前技能与它们所对应的开发快照关系仍以各自冻结记录为准。[最终文件核对](final-check.json) 检查本轮材料、已安装技能和历史结果。v0.5.1 仍未发布到 GitHub。
