# 在“备注：无”之外

《交接单》把人放在物品之后，使读者从表格容不下的内容中认识她们。陈素母亲送饭可以确认；取报告的请求紧邻陈素的接班署名，容易让人担心她，但请求者并未明示，更不能由未签退推断疾病或死亡。日期之间也有空缺，所见是有限记录，并非完整经过。

第一处关键选择是反复写“齐”。三月二日水杯“碎一只，赔款五元已交”，随后“三只，齐”：损失经过赔付与数量调整，又被纳入正常状态。重复不只制造机械感，还训练读者注意细小变项。杯子的减少有明确处理结果，三月七日的“陈素未签退”却只落实为“请联系本人补签”。人当然不能等同于少了一只杯子；正是处理语言的相似，让签字是否齐全与人究竟怎样之间的距离显出来。

第二处是三月四日保留原单与重抄单。“此项请写在请假单上”突然引入纠正者的口吻，但身份不明。“划去，另抄”之后的“备注：无”，对读过上一条的人已不再空白：我们知道曾有人请求两小时代班，却不知道请求后来怎样处理。删改由此成为可见事件。不过，文字只证明它被移出物品交接，不能证明请假遭拒，也不能断言无人关心。

第三处是末条“无姓名，勿倒”与“是否需要编号，待问”的并置。前者要求保留一件来历未明的东西，后者又寻找管理它的方式。记录到此结束，读者没有得到是否编号的答案。保温盒会唤起此前送饭的记忆，但不能确认主人或两者的关系。它留下的是关切的可能，而非人物结局的证据。

一种有依据的不同读法是：规章也可能保护日常生活。椅子修好、盆栽浇水、“勿倒”，都显示具体照料；分开请假与交接也有实务理由。这修正了“制度全然冷酷”的判断，却不能消除人的需要在重抄单上失去位置的事实。

可迁移到航天悬疑的办法，是让固定日志反复出现，再用少数变项和删改暴露人员处境。适用于记录者视野受限、读者能够比较前后条目的故事；风险是把邻近细节写得像唯一答案，诱使读者补出不存在的因果，应保留反证与明确的未知。
