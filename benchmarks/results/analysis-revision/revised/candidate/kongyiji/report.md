# 《孔乙己》：被记住的用途与无人确认的死亡

《孔乙己》的悲剧力度，来自一个人不断争取体面，而酒店始终按自己的用途理解他：在场时供人发笑，不在时留下欠账。身体受损、言语衰弱，都没有促成周围关系的改变。前有“纔可以笑幾聲，所以至今還記得”（块1），后有反复出现的“孔乙己還欠十九個錢呢！”（块2）；这两种记忆互相照亮，显示被记住并不等于被关心。

开篇迟迟不让人物出场，先写酒价、衣着与站坐，实际是在建立辨认人的规则。长衫客能够“慢慢地坐喝”，孔乙己却是“站着喝酒而穿長衫的唯一的人”（块1）：一个姿态组合就暴露了身份愿望与现实待遇的错位。末次来店，他坐在门槛旁，看似终于“坐喝”，却是不能行走的结果（块2）。两种坐姿并不意味着身份升降中的对称转换；相同身体姿态受空间和行动条件约束，反而使尊贵与伤残之间的距离变得可见。

讲述这一切的“我”并非天然站在受害者身旁。“掌櫃是一副凶臉孔”，伙计本来也受压抑，却把孔乙己当作解除无聊的机会（块1）。教字时，他先想“討飯一樣的人，也配考我麽？”，后来才嫌知识无用（块2）。伙计尚未听到教字的用途，贫穷就已成为排斥孔乙己的理由。孔乙己随后提出写账用途，伙计才以自身等级和店里不记豆账回应；后一层质疑有具体店务经验作根据。身份轻蔑与用途不合叠在一起，交流连续受阻，不能仅凭先后就把用途顾虑判成借口。成年后的回忆可能包含对往事的重新理解，但文本没有明确忏悔；不能把叙述呈现的冷酷直接当作叙述者已有的自觉。读者需要从他说得自然的地方，察觉他未曾明说的关系问题。

孔乙己也不能只归结为无辜或迂腐。他以“讀書人的事，能算偸麽？”维护身份（块1），同时又愿意教孩子，并为知识提出“將來做掌櫃的時候，寫帳要用”的理由（块2）。单看“我便考你一考”，像是居高卖弄；连着“便只好向孩子說話”和长久等待来读，则也是成人交流失败后的求伴。伙计指出店里不记豆账，说明这份好意确实误判了对方的需要。分豆后罩住碟子也让给予与匮乏并存，不能只按最后一个动作判他吝啬。至于“好喝嬾做”的身世解释，段首标明“聽人家背地裏談論”（块1）；它提供一种败落原因，却不足以独占人物的全部解释权。

冲突没有靠孔乙己主动反抗逐级推进，而是从可反复上演的取笑，转入严重的身体损伤。酒客叙述打腿经过时，先问“他家的東西，偸得的麽？”（块2），把重点放在丁举人家的不可冒犯，而非惩罚的尺度。过程属于转述，随后亲见只能证实孔乙己严重失去行动能力，不能把传闻每一处都升级为现场事实。掌柜曾连问后续，乍看像关切，但听到“誰曉得？許是死了”便继续算账；好奇没有延伸成寻找。此前守信被称为“品行卻比別人都好，就是從不拖欠”（块1），此后欠账成为想起他的契机（块2），前后都用交易衡量人，因此残疾并未带来新的接待方式。

末次到店最沉重的安排，是延迟看见。先有熟悉的低声，接着“看時又全沒有人”，最后才向下发现门槛旁的身体（块2）；柜台原有的视线高度，暂时把他挡在可见范围外。泥手起初只是细节，“原來他便用這手走來的”才追补行动代价。文言自辩则缩成“跌斷，跌，跌……”，重复不再扩充理由，只勉强维持否认。但他仍说“這一回是現錢，酒要好”（块2），仍要作为付钱的顾客提出要求，故不能断言其自尊已经全失，或换掉长衫便完成醒悟。

前半篇用重复笑声写日常，末尾改用年关、端午、中秋压缩漫长缺席：账话先重现，后来也停了。结句“大約孔乙己的確死了”（块2）中，“大約”保留没有确证的知识限度，“的確”则把长期不见推向强烈结论。无需把矛盾消成一句死亡通知；无人知道确切结局，正延续了前文只管笑话与欠款的关系。死亡的不确定，并不削弱他已经退出众人生活的确定。

独立创作可借用的方法是：先建立一套有具体用途的日常应答，再改变人物处境，观察应答是否改变。操作上，先让某句客套、手续或习惯动作正常出现；再次出现时，让人物失去先前赖以完成互动的条件，并写出代价，避免旁白立即判案。成立条件是两次行为仍处于可比较的关系中，且旁人有机会察觉变化。若处境根本不可比，就不能把动作差异硬说成心理转变；若所有应答都整齐重复，人物又会沦为论点木偶。应保留各人的实际利益与偶然反应，另造人物、场所和事件，不搬用酒账、长衫及本作的独特句式。
