# 五处语义争议复核

依据固定的两个 source.txt、四份原始 report.md 及 comparison.json。段号按原文非空行计，含诗行；字符区间为全文 Unicode 字符从零起算的左闭右开区间，含空白。以下仅提供替换建议，未改动原始证据。

1. 《孔乙己》修订前：诉求是否只剩求饶

原表述：“他起初争取读书人的体面，后来只请求停止取笑”，后文又称“需要已经降到如此低”。

原文依据：第11段“這一回是現錢，酒要好。”[2295,2306)；“但他這回卻不十分分辯，單說了一句『不要取笑！』”[2337,2360)。

处理：收窄。“只”仅能限定当次应对偷窃指责的辩护，不能概括他全部需要。首段和后文“需要”概括须一起改，否则局部增补现钱引文仍会与总论相冲突。

可替换文字：末次到店，孔乙己面对偷窃指责，不再展开“窃书”的辩论，而以“不要取笑”和结巴的否认请求停止揭伤。变化发生在受辱时的应答方式上：他仍强调付现钱、要求酒好，要别人承认自己作为顾客提出要求的资格。买酒得以完成，停止取笑的请求却落了空。他仍在旁人的说笑声中用手离去，身体衰弱并未使掌柜改变羞辱他的惯常方式。

仍不能证明：他已放弃读书人身份、只剩生存需要，或自尊已经丧失。

2. 《孔乙己》修订后：用途顾虑是否只是借口

原表述：“贫穷先取消了说话资格，实用性只是随后补上的理由。”

原文依据：第7段“討飯一樣的人，也配考我麽？”[1397,1410)；“我和掌櫃的等級還很遠呢，而且我們掌櫃也從不將茴香豆上帳”[1478,1505)。

处理：收窄，撤去“只是”所暗示的心理归因，保留拒绝的先后与不同根据。孔乙己提出用途后，伙计才有这个具体主张可反驳，次序也由对话推进造成，不能单独诊断自我辩护。

可替换文字：伙计尚未听到教字的用途，就因孔乙己像讨饭人而转脸拒绝；贫穷已先于知识内容成为排斥他的理由。孔乙己随后提出将来做掌柜写账的用途，伙计又以自身等级和店里不记豆账回应。这后一层质疑有具体店务经验作根据，也显出孔乙己的关照未能贴合孩子的处境。身份轻蔑与用途不合叠在一起，交流因此连续受阻。

仍不能证明：用途考虑纯属托词，或没有身份轻蔑时伙计就会愿意学字。

3. 《命命鸟》修订前：迅速决断是否构成动机单薄

原表述：“长期亲密能说明追随方向，却不足以细写跨越生死的心理门槛”；“动机过渡偏薄”。

原文依据：第11段“我想再入高等學校念書”[1831,1841)；第75段“我不厭世。因爲你底原故，我願意和你同行。”[10258,10278)、“更不料他一下就決心要跟從她”[10470,10483)。

处理：撤回笼统的缺点评价，改为本文内部可见的叙述取舍。前文求学争辩是评价依据；亲密的连续性与末尾婚礼般的叙述则是限制依据，二者都须进入判断。

可替换文字：加陵先前反复向父亲争取求学，湖边却在听到异象之前就答应同行。他以去另一座城比拟死亡，把不愿分离的愿望一直延续到入水，因而迅速决定有其情感连续性，也让轻快显得骇人。这里的代价是：先前经过争辩才保住的求学目标，到此没有再次进入取舍。读者看得见依恋在行动中压过其他目标，却看不到他如何衡量这项牺牲；结尾集中呈现爱情的绝对要求，缩减了前文已有的现实目标协商。

仍不能证明：人物缺乏赴死动机，或补写犹豫一定更好；文本没有承诺以渐进决策呈现死亡。

4. 《命命鸟》修订后：梦中群像是否应有更厚心理

原表述：“梦里所有男女整齐地撒谎、互噬，心理层次较薄”。

原文依据：第55段“各個男子底回答也是一字不改”[7987,8000)、“那班男女立刻變成很凶惡的容貌，互相囓食起來。”[8029,8051)；第57段“好在你不在那邊。幸虧我不能過去。”[8342,8358)。

处理：撤回无条件的审美减分，保留群像被简化及其具体代价。梦中男女承担集体形象的作用，不能仅因没有传记和犹豫就要求增加篇幅；需要指出的是现有突变放弃了哪一层关系解释。

可替换文字：梦中男女越反复宣称唯一，越显出相同承诺可以交给任何对象。狂风随即使他们一同互噬，把许诺失信和肉身伤害压缩在一个突变中。这种齐整迅速放大敏明的恐惧，代价是各对关系的差别、从失信走向伤害的过程都退出画面，读者得到一次笼罩全景的惊吓。敏明醒后却另认自己与加陵为此岸命命鸟；小说的心理分辨集中在她怎样筛选异象、保存两人的特殊归属上。

仍不能证明：梦境提供了现实爱情必然失信伤人的论证，或群像简化本身就是写作缺陷。

5. 《命命鸟》修订后：“误认”的对象与裁定者

原表述：“最后的死亡还需要人物对出路本身发生误认。”

原文依据：第59段“以爲自己沒有向她求婚，所以不高興”[8462,8478)；第75段“知道他與自己底覺悟雖然不同”[10494,10507)；第79段“把他們底軀殼送回來”[10893,10902)。

处理：撤回“误认是死亡必要条件”。分别写实有的情绪误读、已知的动机分歧和未裁定的彼岸信念。

可替换文字：父辈反对尚未封死婚姻；加陵提出逃走时，却把敏明的变化理解为未获求婚的不快，未触及她已经改变的婚姻观。到湖边，她已知道两人觉悟不同，仍以命命鸟身份容许同行。两人分别用离欲与永不分离重述死亡，行动因此会合；这种会合包含对差异的容纳。末尾将返的躯壳使肉身后果重新可见，却仍未裁定他们期待的彼岸是否存在。

仍不能证明：双方始终误以为同心、逃婚对敏明仍是可接受的选择，或宗教归宿已被原文判假。
