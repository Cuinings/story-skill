# 作品分析深度：小型专项材料

本目录提供六组原创合成文本和对应分析任务，用于比较分析流程的具体表现。它们不是名作摘录，不是真实作品样本，也不是“大师级”认证题库。此目录的建立不代表已经完成评测。

每组只把 `source.txt` 和 `task.md` 交给生成分析的模型；不要把本页、评阅协议、其他版本的回答或评阅意见一并交给它。题目不提供标准答案，允许有证据支持的不同解释。

| 编号 | 用途 | 材料 | 重点观察（仅供实验设计者和评阅者） |
| --- | --- | --- | --- |
| 01 | 开发样本 | [原文](development/01/source.txt) · [任务](development/01/task.md) | 日常动作、对话与关系中的潜台词 |
| 02 | 开发样本 | [原文](development/02/source.txt) · [任务](development/02/task.md) | 叙述者的知识边界、修正与可信度 |
| 03 | 开发样本 | [原文](development/03/source.txt) · [任务](development/03/task.md) | 间隔章节组中的信息重估与前后关系 |
| 04 | 开发样本 | [原文](development/04/source.txt) · [任务](development/04/task.md) | 克制表达、缺省信息与解释边界 |
| 05 | 留出样本 | [原文](holdout/05/source.txt) · [任务](holdout/05/task.md) | 不同叙事目标下的节奏评价 |
| 06 | 留出样本 | [原文](holdout/06/source.txt) · [任务](holdout/06/task.md) | 文本形式、重复与主题的关系 |

使用 [评阅协议](protocol.md) 固定生成条件、匿名方法、证据核对和五个评阅维度。先用 01—04 调整流程，再冻结版本与协议，最后一次性使用 05—06。留出文本已经公开在本仓库，只能约束本次实验的接触与使用，不能证明训练数据层面的未知性；如果参与调试的人或模型已读过它们并据此改动流程，应登记污染，另建未参与调试的留出材料。

所有文本均为本项目为此专项编写的虚构材料。人物、场所与事件仅承担测试情境，不指代真实对象。文本短、结构较集中，容易让分析者主动寻找机关；四章片段也只能检验给定片段之间的联系，不能代替读完全书。结果不应推广成作者能力、作品价值、真实市场表现或长篇分析能力的证明。

本目录只保存材料与协议；实际回答、匿名代理评阅及其边界另存于 [本轮试用结果](../results/analysis-depth/README.md)。读取题库本身不能替代检查实际执行记录。
