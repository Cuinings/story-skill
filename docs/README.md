# Story Codex 文档导航

文档版本：v0.4.0，更新日期：2026-09-10。此版本已发布，采用 7 个技能入口，包含中文场景指导和运行时修复；默认安装说明固定到 v0.4.0 标签。Release 附件、固定标签安装、Windows/Linux CI 与公开 Packages 回下载验证均已完成，具体范围集中在 [发布验证记录](github-release.md)。历史 v0.3.0 保留旧单入口结构与固定链接。

## 开始使用

安装或升级都在 Codex 对话框发送同一行，由 Codex 读取指引并调用官方安装脚本：

```text
$skill-installer 按 https://github.com/NingCui29/story-skill/blob/main/INSTALL.md 安装或升级 Story Codex
```

| 要做的事 | 阅读文档 |
|---|---|
| 一行安装、补齐技能或升级已有版本 | [统一安装指引](../INSTALL.md) |
| 复查手动参数、升级方式或发布证据 | [安装与发布](github-release.md) |
| 分清源码、安装副本和书目录 | [目录结构与职责](目录结构.md) |
| 开书、规划、续写和审稿 | [中文小说上手](中文小说上手.md) |
| 改善冲突、人物选择、对白和看点 | [中文冲突与看点](中文冲突与看点.md) |
| 管理百万／千万字长篇的状态与历史修订 | [超长篇实操](超长篇实操.md) |
| 处理导出失败、外部改稿、迁移或依赖问题 | [恢复指南](recovery.md) |

| 内容 | 入口 |

已归档结果：干净检出 **311 项测试、12 项整包检查通过**；多线修订演练完成 **77 次 CLI 检查、28 项断言**；四章中文试写共 **9,297 字**；普通／多线写作冷加载指令为 **4,509／6,149 tokens**。百万与千万字规模通过的是合成容量测试。文学质量、容量、静态指令与实际账户消耗分别评价，不互相替代。

以上数字对应仓库中的本地验证回执；远端工作流的执行状态由 Actions 单独记录。程序、技能或测试变化后，应重新执行对应验证。
