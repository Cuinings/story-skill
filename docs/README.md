# Story Codex 文档导航

当前版本：v0.5.2，准备发布。本版沿用 7 个技能入口、33 个载荷文件和具名分卷正文，补齐大纲层级与规划同步，修复状态保护、历史修订和分析恢复。[v0.5.2 版本说明](releases/v0.5.2.md) 汇总变化；固定标签、Release 附件、远端 CI 和 Packages 的实际状态逐项登记在 [发布验证记录](github-release.md)。

使用说明见 [大纲细纲怎样保存](中文小说上手.md#大纲细纲怎样保存)、[超长篇实操](超长篇实操.md) 和 [恢复流程](recovery.md)。v0.5.2 的验证与测量保存到 [独立记录](../benchmarks/results/v0.5.2/README.md)，远端尚未完成的环节标为待核；v0.5.1 的固定标签、附件及历史数字保留原样。

Windows 正文和报告导出的已知 WinError 32 尚未修复，Windows 用户继续使用固定 v0.4.0；已经用新版写入的书先完整备份，不直接覆盖或降级。本文用法对应 v0.5.2，旧版测量和发布记录保留各自版本范围。

## 开始使用

安装或升级都在 Codex 对话框发送同一行，由 Codex 读取指引并调用官方安装脚本：

```text
$skill-installer 按 https://github.com/NingCui29/story-skill/blob/main/INSTALL.md 安装或升级 Story Codex
```

| 要做的事 | 阅读文档 |
|---|---|
| 一行安装、补齐技能或升级已有版本 | [统一安装指引](../INSTALL.md) |
| 复查手动参数、升级方式或发布证据 | [安装与发布](github-release.md) |
| 分清源码、安装副本和书目录 | [目录结构与职责](目录结构.md) |
| 开书、规划、续写、审稿和作品深读 | [中文小说上手](中文小说上手.md) |
| 查看深读方法、分析稿修订与实际试用 | [作品深读与评估](作品深读与评估.md) |
| 改善冲突、人物选择、对白和看点 | [中文冲突与看点](中文冲突与看点.md) |
| 管理百万／千万字长篇的状态与历史修订 | [超长篇实操](超长篇实操.md) |
| 处理导出失败、外部改稿、迁移或依赖问题 | [恢复指南](recovery.md) |

## 当前实现与证据

v0.5.2 的工程验收、平台结果和分发文件以 [版本说明](releases/v0.5.2.md) 与 [发布验证记录](github-release.md) 为准。作品分析的程序核验与文学评阅分别报告，不用测试通过替代解释是否成立。

| 内容 | 已完成的范围与入口 |
|---|---|
| 开篇点评、完整深读与分析修订 | [深读入口与评估汇总](作品深读与评估.md)，可直接通过 `story-codex-analyze` 使用 |
| 合成短文与完整真实短篇 | [第一轮](../benchmarks/results/analysis-depth/README.md) 和 [第二轮](../benchmarks/results/analysis-real/README.md) 保留匿名模型评阅、分歧及原始材料 |
| 分析稿修订和迁移试用 | [语义修订](../benchmarks/results/analysis-revision/README.md) 与 [恢复试用](../benchmarks/results/analysis-followup/README.md) 保留旧定稿及独立新稿 |
| 完整九章的跨章分析 | [《阿Q正傳》试用](../benchmarks/results/analysis-crosschapter/README.md)：14 块、64 条逐块引文核对通过；独立模型评阅未提出必须修改项，两项可选措辞另存澄清稿 |
| 长篇状态与历史修订 | [超长篇实操](超长篇实操.md) 和 [按版本保存的验收](超长篇验收.md) |
| 文学评阅和实际用量的比较方法 | [评估方法](evaluation.md) |

《阿Q正傳》试用是固定单版本、单作品、一次完整生成及独立模型评阅，没有旧版对照、重复采样或人类编辑。前两轮与后续修订也未证明“大师级”认证、稳定质量提升或实际账户成本下降。各轮冻结技能与输入哈希独立保存，旧输出不追认为最终版生成。

## 已发布历史快照

v0.5.1 于 2026-09-10 发布，增加作品深读、分析示范与修订续跑；本地 397 项测试中 390 项通过、7 项跳过，12 项整包检查及四组合合成容量通过。远端 Linux 通过，Windows 保留已知导出失败。完整范围见 [v0.5.1 版本说明](releases/v0.5.1.md) 与 [原验证记录](../benchmarks/results/v0.5.1/README.md)。

v0.5.0 的 macOS／Python 3.12 本地回归为 379 项测试，其中 372 项通过、7 项平台专用测试跳过；12 项整包检查、四组合合成容量与 v0.4.0 → v0.5.0 的 18 项升级检查通过。Linux 远端检查通过，Windows 存在上述导出失败。[v0.5.0 版本说明](releases/v0.5.0.md) 保留当时的初始化、迁移与发布证据。其普通／多线写作冷加载指令为 **5,324／7,091 tokens**，只统计固定指令。

v0.4.0 已归档结果：干净检出 **311 项测试、12 项整包检查通过**；多线修订演练完成 **77 次 CLI 检查、28 项断言**；四章中文试写共 **9,297 字**；普通／多线写作冷加载指令为 **4,509／6,149 tokens**。[全仓审查与优化](全仓审查与优化.md) 与 [逐文件计数](../benchmarks/results/v0.4.0/tokens.md) 保留原始范围。

百万与千万字规模通过的是合成容量测试。以上旧版结果不作为新版自动通过的依据；文学质量、容量、静态指令与实际账户消耗分别评价。
