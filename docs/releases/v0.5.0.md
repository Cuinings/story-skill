# v0.5.0：具名分卷与章节文件名

发布日期待核验。当前为发布准备稿；本版提交、检查、Release 附件和 Packages 下载结果见 [发布验证记录](../github-release.md#v050-发布验证记录)。历史 v0.4.0 的固定标签、附件、测量和文学评阅保留原样。

## 正文保存规则

新增正文按分卷存放，目录必须包含卷名，章节文件名统一使用不补零的阿拉伯章号：

```text
chapters/
├── 第一卷 雨夜/
│   ├── 第1章 雨中来客.md
│   └── 第2章 门后的灯.md
└── 第二卷 归途/
    └── 第3章 旧站重逢.md
```

卷目录使用 `第X卷 卷名`，短篇和单卷作品同样需要首卷名称。章节计划中的 `volume_dir` 可以直接指定具名卷目录；已有稳定卷 ID 可以复用其已登记目录，或采用已经符合完整命名格式的卷标题。缺少卷名时先补齐规划，不凭空使用无名的“第一卷”或内部 ID。已登记卷 ID 的目录不能被后续章节静默改写。

章节计划的 `title` 优先作为文件标题；未指定时从草稿第一行 Markdown 一级标题提取，并去掉已有的 `第X章` 前缀。新写正文必须有章名。导入无标题的既有正文可以使用章名“正文”，但仍需明确卷名；`adopt --volume-dir "第一卷 雨夜"` 可直接指定导入卷目录。

`lint` 与 `prepare` 会提前检查名称及目标路径。提交、导入和查询回执提供实际路径，历史检查的分页结果也提供当前正文路径；读取时依照这些路径，不再按编号猜测 `0001.md`。

## 改名、外部修改与恢复

修订章名后先完成新路径导出，再处理旧路径；旧稿出现外部修改时保留版本并要求对账。重新发布已完成的历史分支仍可通过分页 `history-inspect` 找到当前正文。召回和历史检查在同一数据库快照内组装正文信息、摘要和路径，避免并发改名造成互相矛盾的回执。

新目标已被文件、链接或等价名称占用时会在写入前拒绝。已登记正文发生外部改稿，仍可先 `lint` 检查修订草稿并取得 `external_edit` 观察；这不授权提交，后续 `prepare --reconcile`、`reconcile` 或历史修订仍独立校验版本与摘要。

导出会将已知的多硬链接正文安全分离为独立文件，保留原版本。目录在操作中被替换时，已绑定的目录句柄用于约束读写与清理；无法完成导出则保留可恢复版本并报告待恢复。若出现多份外部版本，先分别保存到草稿区，再合并审阅；具体步骤见 [恢复指南](../recovery.md)。这些保护不等于已经验证任意外部并发情形。

## 安装与旧书兼容

仍为 7 个同级技能，Python 3.10+，运行时仅用标准库。安装或升级使用 [统一安装指引](../../INSTALL.md)，整套固定到同一版本，并保留已有技能的备份及本地修改。

升级不会重新导入书籍，也不会自动批量搬动旧正文。既有平铺和旧名称导出继续按登记路径发现、读取与恢复；新增正文遵守本版规则。不要让新旧工具同时写同一本书。整卷迁移不在本次自动更新范围内。

## 验证范围

本版 [macOS／Python 3.12 验收](../../benchmarks/results/v0.5.0/verification.json) 完成 375 项测试：368 项通过、7 项平台专用测试跳过、零失败或错误；12 项整包检查全部通过，覆盖七入口元数据、隔离完整安装、三类 CLI 演练、包及报告哈希。[本地 ZIP](../../benchmarks/results/v0.5.0/package.json) 与 [npm 构建](../../benchmarks/results/v0.5.0/npm-package.json) 已核验 7 个技能、31 个载荷文件。[指令 token](../../benchmarks/results/v0.5.0/tokens.md) 已按本版输入重测并核验哈希：普通／多线写作为 5,324／7,091 tokens。远端 Linux／Windows CI、固定标签安装、Release 下载和 Packages 回下载分别记录，未完成的环节不从旧版继承结论。

[合成容量](../../benchmarks/results/v0.5.0/scaling.json) 已在 100 万字／400 章／2,000 张卡片和 1,000 万字／4,000 章／20,000 张卡片两种规模下重新运行，strict、local 四种组合均通过，必需内容超预算时明确拒绝。单次热运行及插桩计数不代表物理磁盘 I/O、完整应用读取或稳定吞吐。

[正式 v0.4.0 套件到 v0.5.0 的升级](../../benchmarks/results/v0.5.0/upgrade.json) 通过 18 项检查，核对完整旧版保留、七入口更新、重复升级及书籍和其他技能不变。[schema 1 迁移与回滚](../../benchmarks/results/v0.5.0/migration.json) 使用固定 v0.2.0 工具生成的长篇、短篇导入和拆文三类中文夹具；原有三本历史旧库在本机缺失，因此这组证据只支持合成夹具迁移，不是历史实书重验。

原有不依赖硬链接的发布方式已有历史 Windows／exFAT 实测；本轮新增目录句柄保护尚待原生 Windows 验证。历史平台测试数不代表本版通过。
